论坛 Godot 版（forum-project-v2）如何打开 —— 避免路径拼错

现象：在「经典论坛」的 Vite 窗口（通常是 http://127.0.0.1:5173 ，base=/forum-project/dist/）
里再输入 forum-project-v2/...，会变成
  /forum-project/dist/forum-project-v2/dist/index.html
这是错的（两个项目不能叠在同一条 dev URL 下）。

正确方式（二选一）：

1) 开发 forum-project-v2 本身
   在本目录执行：npm run dev
   浏览器打开：http://127.0.0.1:5176/
   （5176 与经典论坛 5173 不同端口；需另开终端先起主站 8001，以便 /shared 代理与 API）

2) 测「和线上一致」的静态构建
   npm run build 后，用主站 PHP 托管访问：
   http://127.0.0.1:8001/forum-project-v2/dist/index.html?ui=godot

不要：在 5173 的地址栏后面拼 forum-project-v2/...
