static/
  shell-frame.css    壳布局与 CSS 变量（底图 / 边框 / 覆盖层 / 内嵌区）

  （原有 game-practice-*.css / html 仍在此）

shell/
  common/shell-base.html   可复制改写的模板
  academic|vocabulary|forum/
    shell.html             入口页
    overrides.css          模块变量与配图 url（引用 ../static/shell-frame.css）

assets/
  common|academic|vocabulary|forum/   运行时 Web 使用的成品图（webp/png 等）
  academic/listening/               Listening 选视频页壳配图说明见 README.txt
